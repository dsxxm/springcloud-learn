# JWT 实验手册：双 Token、Redis rotation 与 Gateway

本手册的目标是理解和亲手实现：短期 JWT access token、可撤销的不透明 refresh token、Redis 原子 rotation，以及 Gateway 验证 access token。`jwt/demo/` 当前是骨架；以下 Java/YAML 均是**学习者在实验步骤中创建**的完整文件，不会由本仓库预置。

## 0. 前置条件

**工作目录**：`springcloud-learn/jwt/demo/`

1. Java 17。
2. Redis 可连接到 `localhost:6379`。
3. 生成至少 256 bit 的 HMAC key，保存在 shell 环境变量，不提交 Git：

```bash
export JWT_HS256_KEY_BASE64="$(openssl rand -base64 32)"
```

**为什么**：HS256 的签名密钥是认证根秘密；YAML、日志、前端包和 Git 历史都不应保存它。

**预期**：`printf '%s' "$JWT_HS256_KEY_BASE64" | base64 -d | wc -c` 输出至少 `32`。

## 2. 创建最小认证服务

**工作目录**：`springcloud-learn/jwt/demo/`

**目标文件**：`springcloud-learn/jwt/demo/jwt-auth-service/src/main/resources/application.yml`（学习者创建）。

**目标文件**：`springcloud-learn/jwt/demo/jwt-auth-service/src/main/java/com/macro/cloud/jwt/JwtLabApplication.java`（学习者创建）。

**最终内容**：

```java
package com.macro.cloud.jwt;

import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.SecureRandom;
import java.time.Duration;
import java.time.Instant;
import java.util.Base64;
import java.util.List;
import java.util.Map;
import java.util.UUID;

import javax.crypto.SecretKey;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.Jws;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.security.Keys;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.boot.context.properties.EnableConfigurationProperties;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.data.redis.core.script.DefaultRedisScript;
import org.springframework.http.HttpHeaders;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.stereotype.Service;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestHeader;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@SpringBootApplication
@EnableConfigurationProperties(TokenProperties.class)
public class JwtLabApplication {
    public static void main(String[] args) {
        SpringApplication.run(JwtLabApplication.class, args);
    }
}

@ConfigurationProperties("security.token")
class TokenProperties {
    private String issuer;
    private String audience;
    private String hmacKeyBase64;
    private Duration accessTtl;
    private Duration refreshTtl;

    public String getIssuer() { return issuer; }
    public void setIssuer(String issuer) { this.issuer = issuer; }
    public String getAudience() { return audience; }
    public void setAudience(String audience) { this.audience = audience; }
    public String getHmacKeyBase64() { return hmacKeyBase64; }
    public void setHmacKeyBase64(String hmacKeyBase64) { this.hmacKeyBase64 = hmacKeyBase64; }
    public Duration getAccessTtl() { return accessTtl; }
    public void setAccessTtl(Duration accessTtl) { this.accessTtl = accessTtl; }
    public Duration getRefreshTtl() { return refreshTtl; }
    public void setRefreshTtl(Duration refreshTtl) { this.refreshTtl = refreshTtl; }
}

@Service
class TokenService {
    private static final SecureRandom RANDOM = new SecureRandom();
    private static final String ROTATE_SCRIPT = """
        local saved = redis.call('GET', KEYS[1])
        if not saved then return 0 end
        if saved ~= ARGV[1] then redis.call('DEL', KEYS[1]); return -1 end
        redis.call('SET', KEYS[1], ARGV[2], 'EX', ARGV[3])
        return 1
        """;

    private final StringRedisTemplate redis;
    private final TokenProperties properties;
    private final DefaultRedisScript<Long> rotateScript = new DefaultRedisScript<>(ROTATE_SCRIPT, Long.class);

    TokenService(StringRedisTemplate redis, TokenProperties properties) {
        this.redis = redis;
        this.properties = properties;
    }

    TokenPair login(String userId) {
        return issue(userId, UUID.randomUUID().toString());
    }

    TokenPair refresh(String refreshToken) {
        String[] parts = refreshToken.split("\\.", 2);
        if (parts.length != 2) {
            throw new UnauthorizedException("invalid refresh token format");
        }
        String familyId = parts[0];
        String currentHash = sha256(parts[1]);
        String nextSecret = randomToken();
        Long result = redis.execute(
                rotateScript,
                List.of(refreshKey(familyId)),
                currentHash,
                sha256(nextSecret),
                Long.toString(properties.getRefreshTtl().toSeconds()));
        if (result == null || result != 1L) {
            throw new UnauthorizedException("refresh token expired, reused, or revoked");
        }
        return new TokenPair(mintAccessToken("demo-user", familyId), familyId + "." + nextSecret);
    }

    void logout(String accessToken) {
        Claims claims = parseAccessToken(accessToken);
        String jti = claims.getId();
        String familyId = claims.get("sid", String.class);
        Instant expiresAt = claims.getExpiration().toInstant();
        Duration remaining = Duration.between(Instant.now(), expiresAt);
        if (!remaining.isNegative() && !remaining.isZero()) {
            redis.opsForValue().set("auth:deny:" + jti, "1", remaining);
        }
        redis.delete(refreshKey(familyId));
    }

    Claims parseAccessToken(String accessToken) {
        Jws<Claims> parsed = Jwts.parser()
                .verifyWith(signingKey())
                .requireIssuer(properties.getIssuer())
                .requireAudience(properties.getAudience())
                .build()
                .parseSignedClaims(accessToken);
        if (!"at+jwt".equals(parsed.getHeader().getType())) {
            throw new UnauthorizedException("wrong token type");
        }
        Claims claims = parsed.getPayload();
        if (Boolean.TRUE.equals(redis.hasKey("auth:deny:" + claims.getId()))) {
            throw new UnauthorizedException("access token revoked");
        }
        return claims;
    }

    private TokenPair issue(String userId, String familyId) {
        String refreshSecret = randomToken();
        redis.opsForValue().set(
                refreshKey(familyId), sha256(refreshSecret), properties.getRefreshTtl());
        return new TokenPair(mintAccessToken(userId, familyId), familyId + "." + refreshSecret);
    }

    private String mintAccessToken(String userId, String familyId) {
        Instant now = Instant.now();
        return Jwts.builder()
                .header().type("at+jwt").and()
                .issuer(properties.getIssuer())
                .subject(userId)
                .audience().add(properties.getAudience()).and()
                .id(UUID.randomUUID().toString())
                .claim("scope", "profile.read")
                .claim("sid", familyId)
                .issuedAt(java.util.Date.from(now))
                .notBefore(java.util.Date.from(now))
                .expiration(java.util.Date.from(now.plus(properties.getAccessTtl())))
                .signWith(signingKey())
                .compact();
    }

    private SecretKey signingKey() {
        return Keys.hmacShaKeyFor(Base64.getDecoder().decode(properties.getHmacKeyBase64()));
    }

    private String refreshKey(String familyId) {
        return "auth:refresh:" + familyId;
    }

    private String randomToken() {
        byte[] bytes = new byte[32];
        RANDOM.nextBytes(bytes);
        return Base64.getUrlEncoder().withoutPadding().encodeToString(bytes);
    }

    private String sha256(String value) {
        try {
            return Base64.getEncoder().encodeToString(
                    MessageDigest.getInstance("SHA-256").digest(value.getBytes(StandardCharsets.UTF_8)));
        } catch (Exception exception) {
            throw new IllegalStateException(exception);
        }
    }
}

@RestController
@RequestMapping("/auth")
class AuthController {
    private final TokenService tokens;

    AuthController(TokenService tokens) {
        this.tokens = tokens;
    }

    @PostMapping("/demo-login")
    TokenPair login() {
        return tokens.login("demo-user");
    }

    @PostMapping("/refresh")
    TokenPair refresh(@RequestBody RefreshRequest request) {
        return tokens.refresh(request.refreshToken());
    }

    @PostMapping("/logout")
    ResponseEntity<Void> logout(@RequestHeader(HttpHeaders.AUTHORIZATION) String authorization) {
        tokens.logout(bearer(authorization));
        return ResponseEntity.noContent().build();
    }

    private String bearer(String authorization) {
        if (!authorization.startsWith("Bearer ")) {
            throw new UnauthorizedException("Bearer access token required");
        }
        return authorization.substring(7);
    }
}

record TokenPair(String accessToken, String refreshToken) { }
record RefreshRequest(String refreshToken) { }

class UnauthorizedException extends RuntimeException {
    UnauthorizedException(String message) { super(message); }
}
```

**为什么**：access token 使用独立 `jti` 和短 TTL；refresh token 从不作为 JWT 传给 API，而是以 hash 写入 Redis。Lua 脚本把比较和替换放到 Redis 单线程操作中，两个并发 refresh 不能都成功。重放会删除整个 family。

**命令**：

```bash
mvn -pl jwt-auth-service spring-boot:run
```

**预期**：服务监听 `9301`。`/auth/demo-login` 仅为实验签发固定用户，绝不能复制为生产登录校验。

**边界**：认证服务是 token issuer；它不代理业务请求。Redis 中只保存 refresh secret 的 hash，泄露 Redis 不应直接给攻击者可用 refresh token。

## 3. 验证 rotation、重放和登出

**工作目录**：任意终端。

**目标文件**：无；使用上一步的服务。

**命令**：

```bash
LOGIN="$(curl -s -X POST http://localhost:9301/auth/demo-login)"
REFRESH="$(printf '%s' "$LOGIN" | jq -r .refreshToken)"
ACCESS="$(printf '%s' "$LOGIN" | jq -r .accessToken)"
NEXT="$(curl -s -X POST http://localhost:9301/auth/refresh \
  -H 'Content-Type: application/json' \
  -d "{\"refreshToken\":\"$REFRESH\"}")"
printf '%s\n' "$NEXT"
curl -i -X POST http://localhost:9301/auth/refresh \
  -H 'Content-Type: application/json' \
  -d "{\"refreshToken\":\"$REFRESH\"}"
curl -i -X POST http://localhost:9301/auth/logout \
  -H "Authorization: Bearer $ACCESS"
```

**预期**：第一次 refresh 返回新的 token pair；第二次使用旧 refresh token 得到错误，且该 family 已被删除；logout 删除 refresh family 并以 access token 剩余寿命写入 `auth:deny:{jti}`。

**为什么**：refresh token rotation 的价值是检测并收敛复制后的旧 token 重放。若只是“refresh JWT 验签成功就续期”，无法区分合法刷新和已泄露的同一个 JWT。

**边界**：此示例未注册 `@ControllerAdvice`，异常默认是 500。生产必须把无效/过期/重放 token 统一映射为 `401`，权限不足映射为 `403`，且不向客户端暴露内部判断细节。

## 4. 接入现有 Gateway 的设计检查

**工作目录**：`springcloud-learn/gateway/demo/`

**目标文件**：未来学习者创建的 `springcloud-learn/gateway/demo/gateway-service/src/main/java/com/macro/cloud/gateway/security/JwtAuthenticationFilter.java`；当前仓库尚未创建，避免把教学实现误接入现有网关。

**最终职责**：在 `GlobalFilter` 中仅接受 `Authorization: Bearer <access JWT>`，固定为 HS256 或更推荐的非对称算法，验证 `iss=jwt-auth-service`、`aud=gateway-service`、时间声明和 Redis deny key。成功时把可信 `sub`/`scope` 映射为**内部**请求头；失败立即 `401`，不路由到下游。

**命令**：完成过滤器后，在 `springcloud-learn/gateway/demo/` 运行：

```bash
mvn -pl gateway-service spring-boot:run
```

**预期**：缺少或错误 Bearer token 的受保护路由返回 `401`；有效 access token 才进入 `Path`、`StripPrefix`、`lb://nacos-user-service` 的路由流程。

**边界**：Gateway 不应接收 refresh token，也不应代替认证服务执行 `/auth/refresh`。业务服务若能被外网直接访问，必须额外使用 mTLS、Same-Token 或网络策略防止绕过 Gateway。

## 5. 生产检查表

- 使用 HTTPS；浏览器 refresh token 采用合适的 `HttpOnly`、`Secure`、`SameSite` cookie 策略，并配套 CSRF 防护。
- access token 限短期、最小 scope、精确 audience；不要放 PII。
- 使用密钥轮换和 `kid`；HS256 密钥只在 issuer 与验证者的受控密钥域内可见。
- refresh token 每次 rotation；检测重放时撤销 family；设置绝对过期与闲置超时。
- 密码修改、管理员禁用、风险事件会撤销全部相关 families。
- Redis 必须设置认证、TLS/私网、持久化与高可用策略；不要把 Redis 暴露给公网。
