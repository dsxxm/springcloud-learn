# Spring Cloud OpenFeign 实验手册：声明式调用、负载均衡、降级与日志

本实验按课程创建 `feign-service`：

```text
客户端
  → feign-service:8701
  → OpenFeign UserService
  → Nacos + LoadBalancer
  → nacos-user-service:8206 / :8207
```

项目骨架：

```text
springcloud-learn/openfeign/demo/
├── pom.xml
└── feign-service/
    ├── pom.xml
    └── src/main/
        ├── java/com/macro/cloud/feign/
        │   ├── client/
        │   ├── dto/
        │   └── fallback/
        └── resources/
```

POM 已具备 Nacos Discovery、OpenFeign、LoadBalancer、Resilience4j Circuit Breaker 依赖。后续按完整路径创建源码和配置。

> 本手册遵循课程的完整 User CRUD 契约。开始前，确认你的 `nacos-user-service` 已实现 `/user/create`、`/user/{id}`、`/user/getByUsername`、`/user/update`、`/user/delete/{id}`；若当前用户服务仍是简化版，只先完成 `getUser`、`create` 两个方法的实验。

## 0. 启动 Nacos 与用户服务

在 Nacos 的 `bin/` 目录：

```bash
sh startup.sh -m standalone
```

在以下目录：

```text
springcloud-learn/nacos/demo/
```

启动两个同名服务实例：

```bash
mvn -pl nacos-user-service spring-boot:run
mvn -pl nacos-user-service spring-boot:run \
  -Dspring-boot.run.arguments="--server.port=8207"
```

检查 Nacos 控制台：`nacos-user-service` 有 8206、8207 两个健康实例。

## 2. 创建 DTO

创建：

```text
springcloud-learn/openfeign/demo/feign-service/src/main/java/com/macro/cloud/feign/dto/User.java
```

```java
package com.macro.cloud.feign.dto;

public class User {

    private Long id;
    private String name;
    private String passwd;

    public User() {
    }

    public User(Long id, String name, String passwd) {
        this.id = id;
        this.name = name;
        this.passwd = passwd;
    }

    public Long getId() { return id; }
    public void setId(Long id) { this.id = id; }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public String getPasswd() { return passwd; }
    public void setPasswd(String passwd) { this.passwd = passwd; }
}
```

创建：

```text
springcloud-learn/openfeign/demo/feign-service/src/main/java/com/macro/cloud/feign/dto/CommonResult.java
```

```java
package com.macro.cloud.feign.dto;

public class CommonResult<T> {

    private int code;
    private String message;
    private T data;

    public CommonResult() {
    }

    public CommonResult(T data) {
        this(200, "success", data);
    }

    public CommonResult(int code, String message) {
        this(code, message, null);
    }

    public CommonResult(int code, String message, T data) {
        this.code = code;
        this.message = message;
        this.data = data;
    }

    public int getCode() { return code; }
    public void setCode(int code) { this.code = code; }
    public String getMessage() { return message; }
    public void setMessage(String message) { this.message = message; }
    public T getData() { return data; }
    public void setData(T data) { this.data = data; }
}
```

DTO 字段必须与用户服务的 JSON 契约一致。若提供者返回字段是 `msg` 而不是 `message`，将该字段同步改为 `msg`，或统一双方 DTO。

## 3. 创建完整 Feign Client

创建：

```text
springcloud-learn/openfeign/demo/feign-service/src/main/java/com/macro/cloud/feign/client/UserService.java
```

```java
package com.macro.cloud.feign.client;

import com.macro.cloud.feign.dto.CommonResult;
import com.macro.cloud.feign.dto.User;
import com.macro.cloud.feign.fallback.UserFallbackService;
import org.springframework.cloud.openfeign.FeignClient;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestParam;

@FeignClient(value = "nacos-user-service", fallback = UserFallbackService.class)
public interface UserService {

    @PostMapping("/user/create")
    CommonResult<User> create(@RequestBody User user);

    @GetMapping("/user/{id}")
    CommonResult<User> getUser(@PathVariable("id") Long id);

    @GetMapping("/user/getByUsername")
    CommonResult<User> getByUsername(@RequestParam("username") String username);

    @PostMapping("/user/update")
    CommonResult<User> update(@RequestBody User user);

    @PostMapping("/user/delete/{id}")
    CommonResult<Void> delete(@PathVariable("id") Long id);
}
```

`value = "nacos-user-service"` 必须等于 Nacos 提供者的 `spring.application.name`。`@PathVariable("id")` 和 `@RequestParam("username")` 的参数名称必须保留。

## 4. 创建 Feign 调用 Controller

创建：

```text
springcloud-learn/openfeign/demo/feign-service/src/main/java/com/macro/cloud/feign/UserFeignController.java
```

```java
package com.macro.cloud.feign;

import com.macro.cloud.feign.client.UserService;
import com.macro.cloud.feign.dto.CommonResult;
import com.macro.cloud.feign.dto.User;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/user")
public class UserFeignController {

    private final UserService userService;

    public UserFeignController(UserService userService) {
        this.userService = userService;
    }

    @GetMapping("/{id}")
    public CommonResult<User> getUser(@PathVariable Long id) {
        return userService.getUser(id);
    }

    @GetMapping("/getByUsername")
    public CommonResult<User> getByUsername(@RequestParam String username) {
        return userService.getByUsername(username);
    }

    @PostMapping("/create")
    public CommonResult<User> create(@RequestBody User user) {
        return userService.create(user);
    }

    @PostMapping("/update")
    public CommonResult<User> update(@RequestBody User user) {
        return userService.update(user);
    }

    @PostMapping("/delete/{id}")
    public CommonResult<Void> delete(@PathVariable Long id) {
        return userService.delete(id);
    }
}
```

调用链：

```text
GET feign-service:8701/user/1
  → UserFeignController.getUser(1)
  → UserService.getUser(1)
  → Feign 生成 GET nacos-user-service/user/1
  → LoadBalancer 选择 Nacos 中的 8206 或 8207
  → 返回 CommonResult<User>
```

## 5. 创建 fallback

创建：

```text
springcloud-learn/openfeign/demo/feign-service/src/main/java/com/macro/cloud/feign/fallback/UserFallbackService.java
```

```java
package com.macro.cloud.feign.fallback;

import com.macro.cloud.feign.client.UserService;
import com.macro.cloud.feign.dto.CommonResult;
import com.macro.cloud.feign.dto.User;
import org.springframework.stereotype.Component;

@Component
public class UserFallbackService implements UserService {

    @Override
    public CommonResult<User> create(User user) {
        return new CommonResult<>(new User(-1L, "defaultUser", "123456"));
    }

    @Override
    public CommonResult<User> getUser(Long id) {
        return new CommonResult<>(new User(-1L, "defaultUser", "123456"));
    }

    @Override
    public CommonResult<User> getByUsername(String username) {
        return new CommonResult<>(new User(-1L, "defaultUser", "123456"));
    }

    @Override
    public CommonResult<User> update(User user) {
        return new CommonResult<>(500, "调用失败，服务被降级");
    }

    @Override
    public CommonResult<Void> delete(Long id) {
        return new CommonResult<>(500, "调用失败，服务被降级");
    }
}
```

fallback 必须实现 Feign 接口的全部方法，并且是 Spring Bean。示例默认用户仅用于演示；真实业务应明确告知调用方数据是否陈旧、请求是否可重试，不能把降级数据当作真实用户数据。

## 6. 创建 Feign 日志配置类

创建：

```text
springcloud-learn/openfeign/demo/feign-service/src/main/java/com/macro/cloud/feign/client/FeignConfig.java
```

```java
package com.macro.cloud.feign.client;

import feign.Logger;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class FeignConfig {

    @Bean
    public Logger.Level feignLoggerLevel() {
        return Logger.Level.FULL;
    }
}
```

`FULL` 仅用于学习和短期诊断。生产中应优先 `BASIC`，并避免把认证头、密码或个人信息写入日志。

## 7. 创建完整 application.yml

创建：

```text
springcloud-learn/openfeign/demo/feign-service/src/main/resources/application.yml
```

```yaml
server:
  port: 8701

spring:
  application:
    name: feign-service
  cloud:
    nacos:
      discovery:
        server-addr: localhost:8848
    openfeign:
      circuitbreaker:
        enabled: true
      client:
        config:
          nacos-user-service:
            connectTimeout: 1000
            readTimeout: 3000
            loggerLevel: full

logging:
  level:
    com.macro.cloud.feign.client.UserService: debug
```

`circuitbreaker.enabled=true` 与 POM 中 Resilience4j starter 一起启用 `fallback = UserFallbackService.class`。

## 9. LoadBalancer：直接使用 `@LoadBalanced RestTemplate`

`feign-service` 已经间接使用 LoadBalancer。本节额外创建 `loadbalancer-service`，直接观察服务名解析与实例选择。

### 9.1 创建启动类

```java
@EnableDiscoveryClient
@SpringBootApplication
public class LoadBalancerServiceApplication {

    public static void main(String[] args) {
        SpringApplication.run(LoadBalancerServiceApplication.class, args);
    }
}
```

### 9.2 创建 RestTemplate 配置

创建：

```text
springcloud-learn/openfeign/demo/loadbalancer-service/src/main/java/com/macro/cloud/loadbalancer/RestTemplateConfig.java
```

```java
package com.macro.cloud.loadbalancer;

import org.springframework.cloud.client.loadbalancer.LoadBalanced;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.client.RestTemplate;

@Configuration
public class RestTemplateConfig {

    @Bean
    @LoadBalanced
    public RestTemplate loadBalancedRestTemplate() {
        return new RestTemplate();
    }
}
```

`@LoadBalanced` 让这个 Bean 可以处理 `http://nacos-user-service/...` 形式的服务名 URL。没有该注解时，JVM 会将 `nacos-user-service` 视为普通 DNS 主机名。

### 9.3 创建调用 Controller

创建：

```text
springcloud-learn/openfeign/demo/loadbalancer-service/src/main/java/com/macro/cloud/loadbalancer/UserLoadBalancerController.java
```

```java
package com.macro.cloud.loadbalancer;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.client.RestTemplate;

@RestController
@RequestMapping("/loadbalancer/user")
public class UserLoadBalancerController {

    private final RestTemplate restTemplate;

    public UserLoadBalancerController(RestTemplate restTemplate) {
        this.restTemplate = restTemplate;
    }

    @GetMapping("/{id}")
    public Object getUser(@PathVariable Long id) {
        return restTemplate.getForObject(
                "http://nacos-user-service/user/{id}",
                Object.class,
                id);
    }
}
```

## 10. Sentinel：保护 Feign 调用

本节创建 `sentinel-feign-service`，使用 Sentinel 的 Feign 适配执行流控/熔断后的 fallback。它与第 5 节 Resilience4j fallback 是独立实验；测试本节时，不要在同一个 Client 上开启 Resilience4j fallback。

### 10.1 启动 Sentinel Dashboard

下载 Sentinel Dashboard JAR 后执行：

```bash
java -Dserver.port=8858 -jar sentinel-dashboard.jar
```

浏览器访问：

```text
http://localhost:8858
```

```java
package com.macro.cloud.sentinel.fallback;

import com.macro.cloud.sentinel.client.UserService;

@Component
```
