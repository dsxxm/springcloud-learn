# Nacos 实验手册：文件路径、完整配置与操作顺序

本手册对应已经创建好的项目骨架。所有相对路径都从工作区根目录开始：

```text
springcloud-learn/nacos/demo/
├── pom.xml
├── nacos-user-service/
│   ├── pom.xml
│   └── src/main/
│       ├── java/com/macro/cloud/nacos/user/
│       └── resources/
├── nacos-remote-service/
│   ├── pom.xml
│   └── src/main/
│       ├── java/com/macro/cloud/nacos/remote/
│       └── resources/
└── nacos-config-client/
    ├── pom.xml
    └── src/main/
        ├── java/com/macro/cloud/nacos/config/
        └── resources/
```

`pom.xml` 和全部依赖已经配置好。你只需要按下面路径创建 Java 文件与配置文件；不要重复创建 Maven 模块或添加依赖。

---

## 1. 启动 Nacos Server

### 1.1 Nacos 安装目录

下载并解压 `nacos-server-2.3.0.zip`。以下以解压目录称为 `<nacos-home>`。

确认 `JAVA_HOME` 已指向可用 JDK 后，在 **`<nacos-home>/bin/`** 目录执行：

```bash
# Windows
startup.cmd -m standalone

# Linux / macOS
sh startup.sh -m standalone
```

浏览器访问：<http://localhost:8848/nacos/index.html>

**检查点**：能打开 Nacos 控制台。

## 2. 创建 nacos-user-service

此模块是服务提供者。最终会启动两个实例：`8206`、`8207`。

### 2.1 创建配置文件

创建文件：

```text
springcloud-learn/nacos/demo/nacos-user-service/src/main/resources/application.yml
```

完整内容：

```yaml
server:
  port: 8206

spring:
  application:
    name: nacos-user-service
  cloud:
    nacos:
      discovery:
        server-addr: localhost:8848

management:
  endpoints:
    web:
      exposure:
        include: '*'
```

字段含义：

- `server.port`：当前实例端口；第一个实例是 `8206`。
- `spring.application.name`：注册到 Nacos 的服务名，必须是 `nacos-user-service`。
- `discovery.server-addr`：Nacos Server 地址。

### 2.2 创建完整的启动类

创建文件：

```text
springcloud-learn/nacos/demo/nacos-user-service/src/main/java/com/macro/cloud/nacos/user/NacosUserServiceApplication.java
```

完整内容：

```java
package com.macro.cloud.nacos.user;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.cloud.client.discovery.EnableDiscoveryClient;

@EnableDiscoveryClient
@SpringBootApplication
public class NacosUserServiceApplication {

    public static void main(String[] args) {
        SpringApplication.run(NacosUserServiceApplication.class, args);
    }
}
```

### 2.3 创建完整的 UserController

创建文件：

```text
springcloud-learn/nacos/demo/nacos-user-service/src/main/java/com/macro/cloud/nacos/user/UserController.java
```

完整内容。这里使用内存 `Map` 保存用户，避免数据库干扰 Nacos 实验；之后可按课程替换为 `UserService` 和数据库实现：

```java
package com.macro.cloud.nacos.user;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.atomic.AtomicLong;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/user")
public class UserController {

    private static final Logger LOGGER = LoggerFactory.getLogger(UserController.class);
    private final AtomicLong idSequence = new AtomicLong(1);
    private final Map<Long, Map<String, Object>> users = new ConcurrentHashMap<>();

    public UserController() {
        users.put(1L, new ConcurrentHashMap<>(Map.of(
                "id", 1L,
                "username", "macro",
                "email", "macro@example.com")));
    }

    @GetMapping("/{id}")
    public Object getUser(@PathVariable Long id) {
        Map<String, Object> user = users.get(id);
        if (user == null) {
            return Map.of("code", 404, "message", "用户不存在");
        }
        LOGGER.info("用户查询由当前实例处理，id={}, username={}", id, user.get("username"));
        return Map.of("code", 200, "message", "操作成功", "data", user);
    }

    @GetMapping("/getByUsername")
    public Object getByUsername(@RequestParam String username) {
        return users.values().stream()
                .filter(user -> username.equals(user.get("username")))
                .findFirst()
                .<Object>map(user -> Map.of("code", 200, "message", "操作成功", "data", user))
                .orElse(Map.of("code", 404, "message", "用户不存在"));
    }

    @GetMapping("/getUserByIds")
    public Object getUserByIds(@RequestParam List<Long> ids) {
        List<Map<String, Object>> result = new ArrayList<>();
        for (Long id : ids) {
            Map<String, Object> user = users.get(id);
            if (user != null) {
                result.add(user);
            }
        }
        return Map.of("code", 200, "message", "操作成功", "data", result);
    }

    @PostMapping("/create")
    public Object create(@RequestBody Map<String, Object> user) {
        long id = idSequence.incrementAndGet();
        Map<String, Object> savedUser = new ConcurrentHashMap<>(user);
        savedUser.put("id", id);
        users.put(id, savedUser);
        return Map.of("code", 200, "message", "操作成功", "data", savedUser);
    }

    @PostMapping("/update")
    public Object update(@RequestBody Map<String, Object> user) {
        Object rawId = user.get("id");
        if (rawId == null) {
            return Map.of("code", 400, "message", "id 不能为空");
        }
        long id = Long.parseLong(rawId.toString());
        if (!users.containsKey(id)) {
            return Map.of("code", 404, "message", "用户不存在");
        }
        Map<String, Object> savedUser = new ConcurrentHashMap<>(user);
        savedUser.put("id", id);
        users.put(id, savedUser);
        return Map.of("code", 200, "message", "操作成功", "data", savedUser);
    }

    @PostMapping("/delete/{id}")
    public Object delete(@PathVariable Long id) {
        return users.remove(id) == null
                ? Map.of("code", 404, "message", "用户不存在")
                : Map.of("code", 200, "message", "操作成功");
    }
}
```


### 2.4 启动第一个实例

在以下目录执行：

```text
springcloud-learn/nacos/demo/
```

命令：

```bash
mvn -pl nacos-user-service spring-boot:run
```

**检查点**：Nacos 控制台「服务管理 → 服务列表」出现 `nacos-user-service`，实例端口为 `8206`。

### 2.5 启动第二个实例

保持第一个实例运行，另开终端，仍进入：

```text
springcloud-learn/nacos/demo/
```

执行：

```bash
mvn -pl nacos-user-service spring-boot:run -Dspring-boot.run.arguments="--server.port=8207"
```

不需要新建第二份 `application.yml`。命令行参数优先级高于 YAML 中的 `server.port: 8206`。

**检查点**：Nacos 控制台中仍是一个 `nacos-user-service` 服务，但实例数量为 2，端口是 `8206` 和 `8207`。

## 3. 创建 nacos-remote-service

此模块是消费者：它注册到 Nacos，再通过服务名调用 `nacos-user-service`。

### 3.1 创建完整配置文件

创建文件：

```text
springcloud-learn/nacos/demo/nacos-remote-service/src/main/resources/application.yml
```

完整内容：

```yaml
server:
  port: 8308

spring:
  application:
    name: nacos-remote-service
  cloud:
    nacos:
      discovery:
        server-addr: localhost:8848

service-url:
  nacos-user-service: http://nacos-user-service
```

这里 `http://nacos-user-service` 不是固定 IP，也不是普通 DNS 域名。`@LoadBalanced RestTemplate` 会将它解析为 Nacos 中同名服务的健康实例。

### 3.2 创建完整的启动类

创建文件：

```text
springcloud-learn/nacos/demo/nacos-remote-service/src/main/java/com/macro/cloud/nacos/remote/NacosRemoteServiceApplication.java
```

完整内容：

```java
package com.macro.cloud.nacos.remote;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.cloud.client.discovery.EnableDiscoveryClient;
import org.springframework.cloud.client.loadbalancer.LoadBalanced;
import org.springframework.context.annotation.Bean;
import org.springframework.web.client.RestTemplate;

@EnableDiscoveryClient
@SpringBootApplication
public class NacosRemoteServiceApplication {

    public static void main(String[] args) {
        SpringApplication.run(NacosRemoteServiceApplication.class, args);
    }

    @Bean
    @LoadBalanced
    public RestTemplate restTemplate() {
        return new RestTemplate();
    }
}
```

`@LoadBalanced` 会为这个 `RestTemplate` 加入服务名解析能力；下面 Controller 中的 `http://nacos-user-service` 才能被解析为 Nacos 中的实例地址。

### 3.3 创建完整的 RemoteUserController

创建文件：

```text
springcloud-learn/nacos/demo/nacos-remote-service/src/main/java/com/macro/cloud/nacos/remote/RemoteUserController.java
```

完整内容：

```java
package com.macro.cloud.nacos.remote;

import java.util.Map;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.client.RestTemplate;

@RestController
@RequestMapping("/user")
public class RemoteUserController {

    private final RestTemplate restTemplate;

    @Value("${service-url.nacos-user-service}")
    private String userServiceUrl;

    public RemoteUserController(RestTemplate restTemplate) {
        this.restTemplate = restTemplate;
    }

    @GetMapping("/{id}")
    public Object getUser(@PathVariable Long id) {
        return restTemplate.getForObject(
                userServiceUrl + "/user/{id}",
                Object.class,
                id);
    }

    @GetMapping("/getByUsername")
    public Object getByUsername(@RequestParam String username) {
        return restTemplate.getForObject(
                userServiceUrl + "/user/getByUsername?username={username}",
                Object.class,
                username);
    }

    @PostMapping("/create")
    public Object create(@RequestBody Map<String, Object> user) {
        return restTemplate.postForObject(
                userServiceUrl + "/user/create",
                user,
                Object.class);
    }

    @PostMapping("/update")
    public Object update(@RequestBody Map<String, Object> user) {
        return restTemplate.postForObject(
                userServiceUrl + "/user/update",
                user,
                Object.class);
    }

    @PostMapping("/delete/{id}")
    public Object delete(@PathVariable Long id) {
        return restTemplate.postForObject(
                userServiceUrl + "/user/delete/{id}",
                null,
                Object.class,
                id);
    }
}
```

一次 `GET http://localhost:8308/user/1` 的实际转发链路：

```text
浏览器/curl
  → nacos-remote-service:8308 的 /user/1
  → RemoteUserController.getUser(1)
  → RestTemplate 请求 http://nacos-user-service/user/1
  → @LoadBalanced 从 Nacos 获取 nacos-user-service 健康实例
  → 8206 或 8207 的 /user/1
  → 原样返回提供者响应
```

这里绝不能写 `http://localhost:8206`；那会跳过 Nacos，永远固定调用 8206。

### 3.4 启动和验证

在 **`springcloud-learn/nacos/demo/`** 目录执行：

```bash
mvn -pl nacos-remote-service spring-boot:run
```

连续多次调用：

```bash
curl http://localhost:8308/user/1
```

**检查点**：两个 `nacos-user-service` 实例的日志交替输出查询日志。说明 remote-service 经服务名发现实例，并通过客户端负载均衡选择实例。

## 4. 创建 nacos-config-client

此模块演示 Nacos 配置中心与动态刷新。课程使用 `application.yml + bootstrap.yml`。

### 4.1 创建 application.yml

创建文件：

```text
springcloud-learn/nacos/demo/nacos-config-client/src/main/resources/application.yml
```

完整内容：

```yaml
spring:
  profiles:
    active: dev
```

这个文件只负责激活 `dev` 环境。

### 4.2 创建 bootstrap.yml

创建文件：

```text
springcloud-learn/nacos/demo/nacos-config-client/src/main/resources/bootstrap.yml
```

完整内容：

```yaml
server:
  port: 9101

spring:
  application:
    name: nacos-config-client
  cloud:
    nacos:
      discovery:
        server-addr: localhost:8848
      config:
        server-addr: localhost:8848
        file-extension: yaml
```

此项目的 POM 已有 `spring-cloud-starter-bootstrap`。不要把上述配置写进 `application.yml`，也不要另加 `spring.config.import`。

### 4.3 在 Nacos 控制台创建配置

Data ID 由下面公式推导：

```text
${spring.application.name}-${spring.profiles.active}.${spring.cloud.nacos.config.file-extension}
```

当前变量代入后：

```text
nacos-config-client-dev.yaml
```

打开 Nacos 控制台：**配置管理 → 配置列表 → 新建配置**，填写：

| 字段 | 值 |
|---|---|
| Data ID | `nacos-config-client-dev.yaml` |
| Group | `DEFAULT_GROUP` |
| 配置格式 | `YAML` |

配置内容完整写为：

```yaml
config:
  info: "config info for dev"
```

点击“发布”。

### 4.4 创建完整的启动类

创建文件：

```text
springcloud-learn/nacos/demo/nacos-config-client/src/main/java/com/macro/cloud/nacos/config/NacosConfigClientApplication.java
```

完整内容：

```java
package com.macro.cloud.nacos.config;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.cloud.client.discovery.EnableDiscoveryClient;

@EnableDiscoveryClient
@SpringBootApplication
public class NacosConfigClientApplication {

    public static void main(String[] args) {
        SpringApplication.run(NacosConfigClientApplication.class, args);
    }
}
```

### 4.5 创建完整的 ConfigClientController

创建文件：

```text
springcloud-learn/nacos/demo/nacos-config-client/src/main/java/com/macro/cloud/nacos/config/ConfigClientController.java
```

完整内容：

```java
package com.macro.cloud.nacos.config;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.cloud.context.config.annotation.RefreshScope;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RefreshScope
@RestController
public class ConfigClientController {

    @Value("${config.info}")
    private String configInfo;

    @GetMapping("/configInfo")
    public String getConfigInfo() {
        return configInfo;
    }
}
```

`@RefreshScope` 是动态刷新的关键：Nacos 发布新配置后，访问 `/configInfo` 才会读取重新绑定的 `configInfo`。


### 4.6 启动和验证

在 **`springcloud-learn/nacos/demo/`** 目录执行：

```bash
mvn -pl nacos-config-client spring-boot:run
```

请求：

```bash
curl http://localhost:9101/configInfo
```

**检查点**：返回：

```text
config info for dev
```

### 4.7 验证动态刷新

在控制台编辑同一份 `nacos-config-client-dev.yaml`，改为：

```yaml
config:
  info: "config info for dev update"
```

发布后，**不要重启** `nacos-config-client`。重新请求：

```bash
curl http://localhost:9101/configInfo
```

**检查点**：返回 `config info for dev update`。日志通常会出现 `config changed`、`data-received`、`Refresh keys changed`。

## 5. 开启 Nacos 鉴权（完成前四步后再做）

编辑 Nacos 安装目录中的文件：

```text
<nacos-home>/conf/application.properties
```

加入或修改为：

```properties
nacos.core.auth.system.type=nacos
nacos.core.auth.enabled=true
nacos.core.auth.server.identity.key=example
nacos.core.auth.server.identity.value=example
nacos.core.auth.plugin.nacos.token.secret.key=SecretKey012345678901234567890123456789012345678901234567890123456789
```

重启 Nacos。课程对应版本默认账号密码为 `nacos / nacos`。

之后在每个模块的 Nacos 配置中补充：

```yaml
username: nacos
password: nacos
```

位置分别是：

- user-service 与 remote-service：各自 `application.yml` 的 `spring.cloud.nacos.discovery` 下；
- config-client：`bootstrap.yml` 的 `spring.cloud.nacos.discovery` 和 `spring.cloud.nacos.config` 下。

完整示例：

```yaml
spring:
  cloud:
    nacos:
      discovery:
        server-addr: localhost:8848
        username: nacos
        password: nacos
      config:
        server-addr: localhost:8848
        username: nacos
        password: nacos
        file-extension: yaml
```

生产环境不能使用课程给出的账号和 Token。
